ShipOS

0.2.0-beta.4 · Windows 10/11 x64 · free MIT donationware

ShipOS is a local Space Engineers telemetry and Storytelling companion. Setup is offline and installs for the current Windows user without normally requiring administrator access.

Public beta: this executable is not yet code-signed. Download it only from the official syncrotellabs website, compare its SHA-256 checksum, and do not run it if the source or checksum is uncertain.

What is included

  • ShipOS web app, private Node.js 24 runtime, and embedded SQLite support
  • Tray helper and Start-menu launch/uninstall shortcuts
  • Optional ShipOSLocalTelemetry world mod

Nothing is downloaded during setup. No system Node.js, database server, plugin loader, account, subscription, or cloud service is needed.

Requirements

  • 64-bit Windows 10 or 11, .NET Framework 4.x, and Windows PowerShell 5.1
  • 250 MB free minimum, plus space for retained rollback copies
  • Space Engineers for live telemetry; Storytelling works without the game
  • A modern WebGL browser

After setup

  1. Enable ShipOSLocalTelemetry in the save's Mods list.
  2. Fully reload the world.
  3. Start ShipOS from Start or the tray helmet.
  4. For a tablet, Android device, or another PC, enable local sharing and open the one-time QR/link on the same trusted network.

LAN sharing uses unencrypted HTTP. Never port-forward ShipOS or expose it to the internet.

Help and privacy

Setup includes a copyable readiness report. Additional documentation is included in the portable package and on the download page. ShipOS contains no analytics or syncrotellabs data collection. Optional AI requires a separately installed local compatible service.
