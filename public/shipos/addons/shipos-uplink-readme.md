# Local beta setup

Install ShipOS with its Windows installer, enable the bundled **ShipOSLocalTelemetry** mod in your single-player save, then reload the world. The helper directly reads the mod's local telemetry file. No programmable block, plugin loader, sign-in, or relay is needed.

The helmet tray menu opens ShipOS at `http://127.0.0.1:5174/`. Use **Show iPad QR code…**, enable local sharing, and generate a one-use code for the tablet. The PC must remain running. Full instructions and the security limitations are in the application README.
