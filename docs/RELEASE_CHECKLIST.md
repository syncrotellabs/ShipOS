# Donationware release checklist

- [x] MIT license; no subscriptions, paid tiers, or internet relay in the active runtime.
- [x] Two main pages: concise Telemetry and experimental Storytelling.
- [x] Zero-state campaign, first-visit beta notice, closed configuration drawer.
- [x] Shared local SQLite, per-world profiles, revision checks, backups and recovery drafts.
- [x] Local-only default, explicit LAN sharing, account-free read/write pairing, PC-only administration, revocation.
- [x] Bundled-runtime offline installer, shortcut/tray lifecycle, opt-in startup, uninstaller and checksums.
- [x] Current-PC isolated install/upgrade/uninstall test and core regression suite.
- [x] Versioned release notes, requirements, privacy, support, website copy and machine-readable release manifest.
- [ ] Live character/cockpit/world-transition verification after reloading the updated mod.
- [ ] Actual iPad Safari QR, touch, reconnect, and long-session tests.
- [ ] Actual local AI model end-to-end test (manual story tools do not require it).
- [ ] Clean second-Windows-PC validation.
- [ ] Authorized code-signing identity and signed release artifacts.
- [ ] Inherited asset provenance, product-name and current game-policy review.
- [ ] Accessibility, performance, disk-full recovery, security fuzzing, and soak tests.
- [ ] CI/release automation and final owner approval of donation/download website content.

See [BETA_ACCEPTANCE.md](BETA_ACCEPTANCE.md) for evidence and known limitations. Beta.4 is a website-ready **unsigned public-beta candidate**, not a signed stable release.
