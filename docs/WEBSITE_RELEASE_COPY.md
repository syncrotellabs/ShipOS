# Website copy — ShipOS 0.2.0-beta.5

## Short description

ShipOS is a free, open-source local companion for Space Engineers. View live planetary telemetry, focus on tagged friendly grids, and keep a shared roleplay/story workspace from your gaming PC, tablet, phone, or another PC on your private network.

## Linux availability

Dynasty Chronicle has a Linux version, but ShipOS is currently Windows-only. Medieval Dynasty actually runs better for me on Linux than it does on my Windows machine; Space Engineers, however, has not yet been tested for this project on Linux, and its Wine AppDB compatibility information has included a **“Garbage”** rating. Because of that, I am not claiming Linux support for ShipOS today.

I plan to try Space Engineers on Linux eventually. If I can get it working reliably, I may explore a Linux version of ShipOS as well—but that is a possibility, not a promise.

## Download section

**ShipOS 0.2.0-beta.5 for Windows 10/11 x64 — public beta**

The one-click offline setup includes ShipOS, a private Node.js runtime, the tray helper, and `ShipOSLocalTelemetry`. It safely backs up and enables telemetry in the latest local save, starts with Windows, and opens the app. No account, subscription, cloud relay, system-wide Node installation, database server, or Mods-menu work is required.

Before installing, read the included Requirements, Privacy, Security, and Support documents. Verify the download against `SHA256SUMS.txt`.

**Beta warning:** the executable is currently unsigned, LAN sharing is unencrypted and for trusted private networks only, and Storytelling/AI content is experimental fiction. ShipOS is unofficial and is not endorsed by Keen Software House.

## Donation copy

ShipOS is donationware: every feature is free, the source is available under the MIT License, and there are no paid tiers. If ShipOS adds something enjoyable to your game, an optional donation helps fund testing, code signing, documentation, and future development. Donations do not unlock features or create an account.

## Installation summary

1. Run setup and choose **Install ShipOS**.
2. Start Space Engineers normally; the latest local save is already configured.
3. If the game was open during setup, exit and reopen it once.
4. To use a tablet or another PC, enable local sharing and open the single-use QR/link on the same trusted network.
